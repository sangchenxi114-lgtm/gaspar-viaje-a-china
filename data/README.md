# 加斯帕尔中国南部旅行历史地理数据集

本目录整理用户提供的《游历地点梳理(1).docx》，共32条地点或场景记录；未进行外部坐标定位或独立历史考证。

## 文件

- `places.csv`：UTF-8 BOM编码的表格；字面量 `null` 表示缺失值。
- `journey.json`：包含方法说明和 `places` 数组；使用JSON原生 `null`。
- `README.md`：数据说明及质量报告。
- 仓库根目录 `data_quality_report.md`：单独保留的质量报告。

## 使用与方法

每条记录包含用户要求的19个字段，以及来源分组、日期依据、亲历状态和观察／考证来源字段。`sequence` 表示笔记顺序，不是已证实的旅行路线。日期仅来自笔记分组；无日期的章节保持为空。全部坐标为空，状态为 `unknown`，不以城市中心替代历史地点。

`identification_confidence` 使用 `confirmed`、`probable`、`possible`、`unidentified`；`coordinate_status` 使用 `exact`、`approximate`、`city-level`、`unknown`。当前城市名称层面的明确识别不代表精确地址或到访日期已获证实。

`original_spanish` 及 `gaspar_observation` 保留附件引述；`researcher_identification` 保存整理者标签，相关疑点记录于 `historical_notes`。P022引述内的中文插注原样保留并标明性质。`visit_status` 区分明确在场、笔记明确非亲历和证据不足；P024瓷塔为非亲历记录。

现状、图像及3D模型链接未提供，保持为空。来源参考指向附件章节、条目和段落，不代表原作版本或页码。尚未获得数据集批准；不应直接将全部记录绘制为连续亲历路线，本次未创建网站或交互式地图。
